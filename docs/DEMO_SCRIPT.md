# 演示流程脚本

## 1. 普通商城商品浏览

- 操作入口：`http://localhost:5173/user/home`
- 输入示例：使用普通用户登录后进入商城首页。
- 预期效果：展示 Banner、分类、今日特价、推荐商品、购物车入口。
- 展示亮点：商城业务不是静态页面，商品来自 MySQL。

## 2. AI 智能导购

- 操作入口：`/ai/guide`
- 输入示例：`推荐500元以内适合跑步的无线耳机`
- 预期效果：AI 回复推荐理由，并展示商品卡片。
- 展示亮点：Agent 通过 ProductTool 查询真实商品，不编造商品。

## 3. 语义化商品搜索

- 操作入口：`/ai/search`
- 输入示例：`适合宿舍用的安静小风扇，价格别太贵`
- 预期效果：返回标准化关键词、标签和匹配商品。
- 展示亮点：能处理模糊自然语言，比传统关键词搜索更灵活。

## 4. 智能客服查单

- 操作入口：`/ai/customer-service`
- 输入示例：`我的订单怎么还没发货？`
- 预期效果：识别订单查询或售后意图，给出客服回复。
- 展示亮点：客服只基于 OrderTool / UserTool 数据回答。

## 5. RAG 售后规则问答

- 操作入口：Postman 或 AI 工作台。
- 输入示例：`商品签收后几天内可以无理由退货？`
- 预期效果：根据知识库片段回答，并返回来源。
- 展示亮点：无依据时不会编造平台政策。

## 6. 商家文案生成

- 操作入口：`/admin/ai/workbench`
- 输入示例：`帮商品1001生成开学季营销文案`
- 预期效果：生成标题、卖点、详情、促销文案。
- 展示亮点：只生成建议文案，不自动覆盖商品信息。

## 7. 评论智能分析

- 操作入口：`/admin/ai/workbench`
- 输入示例：选择评论分析模板，填写商品 ID。
- 预期效果：输出情感统计、差评问题、回复建议。
- 展示亮点：回复建议需要人工审核，不自动发布。

## 8. 订单数据分析

- 操作入口：`/admin/ai/workbench`
- 输入示例：`分析2024-06-01到2024-06-30订单数据`
- 预期效果：输出订单数、销售额、客单价、复购率和 Markdown 报告。
- 展示亮点：核心指标 Java 侧计算，AI 只做解释和建议。

## 9. 库存销售分析

- 操作入口：`/admin/ai/inventory`
- 输入示例：选择库存分析，填写时间范围和商品 ID。
- 预期效果：展示库存风险、补货建议、滞销商品建议。
- 展示亮点：库存周转、预计售罄天数等指标可解释。

## 10. 多 Agent 工作台统一入口

- 操作入口：`/admin/ai/workbench`
- 输入示例：`本月运营简报`
- 预期效果：自动识别意图并路由到对应 Agent。
- 展示亮点：内容安全审核、角色权限、意图识别、Agent 路由完整闭环。

## 演示建议顺序

```text
登录 -> 商城浏览 -> AI导购 -> 语义搜索 -> 智能客服 -> RAG问答
-> 商家工作台 -> 评论分析 -> 订单分析 -> 库存分析 -> 统一工作台
```
